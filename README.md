# Airbnb-Revenue-Management

This repo used to hold multiple unrelated Airbnb/PriceLabs tools mixed
together in one folder. They've each been split out into their own
dedicated repo:

- **Daily Low & High Price Analysis** (per-property mispricing flags,
  Airbnb promo tracking, PriceLabs overrides mirror) --
  [teltic/Airbnb-Promotion-Price-Range-Tool](https://github.com/teltic/Airbnb-Promotion-Price-Range-Tool)
- **Booking Quality Log** (one log of every confirmed booking, flagging
  upsell/discount-worthy gaps and below-target pricing) --
  [teltic/Booking-Quality-Tracker](https://github.com/teltic/Booking-Quality-Tracker)

Nothing runnable lives in this repo anymore -- it's kept around as a
pointer to where things moved.
